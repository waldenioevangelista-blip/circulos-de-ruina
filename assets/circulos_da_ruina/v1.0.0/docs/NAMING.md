# Padrão de nomes — Círculos de Ruína

Formato: `[dominio]_[categoria]_[assunto]_[variante]_vNN.ext`

## Exemplos
- `ui_screen_detalhe_sentinela_mobile_v01.png`
- `unit_portrait_sentinela_sal_default_v01.png`
- `arena_concept_ruinas_arcanas_dia_v01.png`
- `vfx_effect_muralha_sal_cast_v01.png`

## Regras
- Sempre em minúsculas.
- Separador único: `_`.
- Sem espaços, acentos ou nomes genéricos como `final`, `novo`, `teste2`.
- Aumentar somente o sufixo de versão ao criar revisão aprovada.
- A fonte gerada permanece preservada; a cópia aprovada recebe nome semântico.
